# ПСС Music Downloader — расширение для Firefox

Сохраняет треки в MP3, чтобы слушать их офлайн. Работает на `vk.ru`, `vk.com` и
их поддоменах: ловит ссылки, которые сайт сам отдаёт вашему авторизованному
плееру, и складывает их в список с кнопками скачивания.

## Установка

### Временное расширение (для проверки)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выберите **`manifest.json`** из папки
   `vk-music-downloader`.
3. Иконка появится на панели. Живёт до перезапуска браузера.

### Постоянная установка

Обычный Firefox не ставит неподписанные `.xpi`, поэтому пакет подписывается в
AMO как **unlisted** (self-distribution):

```
npx web-ext sign --source-dir vk-music-downloader --channel unlisted \
  --api-key=<JWT issuer> --api-secret=<JWT secret>
```

Полученный `.xpi` открывается двойным кликом и ставится навсегда.

## Как пользоваться

1. Откройте музыкальный раздел на `vk.ru` и включите трек или полистайте
   список — ссылки подхватятся автоматически.
2. Нажмите иконку расширения на панели Firefox.
3. «Скачать» у трека или «Скачать все». Файлы падают в
   `Загрузки/ПСС Music/<Исполнитель> - <Название>.mp3`.

В попапе есть фильтр по названию и исполнителю, кнопка очистки и «Диагностика» —
она сохраняет JSON-отчёт о последних перехваченных ответах (без токенов), если
что-то не ловится.

## Как это устроено

- `background.js` — фоновая страница. Через `webRequest.filterResponseData`
  читает ответы внутреннего API (`/method/*`, `al_audio.php`, всё, где в пути
  есть `audio` или `music`) и рекурсивно ищет в JSON объекты с полями
  `url/title/artist`.
- **Названия берутся из трёх источников**: поля ответа API → ID3-теги самого
  файла (`TIT2`/`TPE1`, поддержаны ID3v2.2/2.3/2.4, кодировки UTF-8/UTF-16/
  Latin-1) → имя файла в ссылке. Теги дочитываются лениво: первые 256 КБ
  запросом `Range`, по 3 потока, только для треков без названия.
- Скачивание — `browser.downloads.download` по прямой ссылке; если CDN отказал
  (истёк токен, 403) — запасной путь через `fetch` с куками и blob.
- Интерфейс — только попап на панели браузера. На страницах сайта расширение
  ничего не рисует.

Расширение ничего не подделывает и не обходит: используются только те ссылки,
которые сервис выдаёт вашей сессии. Если трек доступен лишь по подписке, ссылки
в ответе не будет — расширение её не синтезирует.

## Ограничения

- Потоковые треки (HLS/`m3u8`) не поддерживаются — нужен прямой `mp3`/`m4a`.
- Ссылки на CDN живут ограниченное время: если трек в списке давно, включите его
  ещё раз в плеере — URL обновится, ключ трека останется прежним.
- Если в файле нет ID3-тегов, название берётся из имени файла или остаётся
  «Без названия».

## Если ничего не ловится

1. Откройте попап → «Диагностика» и посмотрите, какие ответы перехвачены.
2. В DevTools → Network отфильтруйте `audio`: если запросы идут на другой хост
   или путь, добавьте шаблон в `API_URLS` в `background.js`.
3. Проверьте, что расширению выданы права на `*.vk.ru`, `*.vk.com`,
   `*.userapi.com` (about:addons → разрешения).

## Правовая оговорка

Инструмент для личного офлайн-прослушивания того, к чему у вас уже есть доступ в
аккаунте. Он не снимает защиту и не обходит подписку. Скачанные файлы остаются
объектами авторского права — не выкладывайте их в общий доступ и учитывайте
условия использования сервиса.
